## Мета роботи
Вивчити та закріпити на практиці можливості системи керування версіями, одержати практичний досвід у використанні Git та GitHub.

## Теоретичні відомості
Система керування версіями (SCM) — це програмний інструмент для відстеження та керування змінами у вихідному коді чи документах. Вони поділяються на централізовані (Subversion, TFS) та розподілені (Git, Mercurial). Git дозволяє кожному розробнику мати повну локальну копію репозиторію, створювати ізольовані гілки (branch) та об'єднувати їх через Pull Request.
